# Azerbaijani Automatic Speech Recognition (ASR) System

This repository contains an ASR pipeline developed for the Azerbaijani language as part of the AI Engineer Internship technical task. The project utilizes the **Whisper-Tiny** model and the **Mozilla Common Voice 25.0** dataset.

## Project Structure
- `part_a/`: Baseline implementation and inference code.
- `part_b/`: Fine-tuning scripts and training logs.
- `results/`: Performance metrics (WER/CER) and visualizations.
- `report.pdf`: Analytical report on technical challenges and solutions.
